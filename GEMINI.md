# Jobs Data Intelligence

Live job listings from Greenhouse, Lever, Ashby, Workday, EURES, Reed, Wellfound, Y Combinator and remote boards.

Use the tools of the `Jobs Data Intelligence` MCP server when the user asks for this data. Ask for a small `limit` first and widen it only when asked. If a call answers 401, the MCPize API key is missing or expired: tell the user to run `gemini extensions config` for this extension.
